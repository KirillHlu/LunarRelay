04 / BEFORE YOU GO

Any questions?

What is Lunar Relay?+

A first-person educational game about operating a future lunar outpost, created as a NASA Space Apps Challenge project. You manage connected air, water and power systems while completing crew tasks. This is not an official NASA product.

What is a mission seed?+

A seed is a number that sets the initial mission conditions. Use the same number to replay a familiar scenario or compare results under the same conditions.

How does the game use science?+

CO₂ removal, oxygen production, water use and power distribution are separate, connected systems. Time is accelerated, and parameters and events are adapted for learning. This is a simulation, not a live NASA data feed.

Can I play on iPhone or in a browser?+

Android and Windows downloads are available here. There is no iPhone or browser-playable version on this page.

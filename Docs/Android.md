# Android

Сборка для Android 8.0+ (API26), процессоры ARM64, горизонтальный экран. APK для прямой установки, с тестовой подписью Unity. Это не публикация в Google Play.

Установка: скопируйте LunarRelay.apk на телефон, откройте файл и разрешите установку приложений для используемого файлового менеджера. Затем выберите «Установить».

Управление: крестовина слева — движение; свайп в правой средней части экрана — обзор; справа — действие, убрать/бросить предмет, фонарь, прыжок и приседание. Снизу — Tab, рюкзак, пауза. В режиме декора отдельные кнопки «Установить», «Повернуть», «Отмена». Инвентарь, Shop и сохранения доступны через существующие экраны.

Используется Mobile URP, OpenGL ES3, цель30 кадров/с и учёт вырезов экрана. На реальном телефоне частота кадров пока не измерена.

Повторная сборка Unity6000.3.25f1: -batchmode -nographics -quit -buildTarget Android -projectPath PATH -executeMethod LunarRelay.Editor.BuildTools.AndroidPhone. Нужны Android Build Support, SDK, NDK и OpenJDK. AndroidPhone меняет настройки графики в сборочном проекте; для последующих Windows-сборок используйте исходные PC-настройки проекта.

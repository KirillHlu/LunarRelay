Original Lunar Relay equipment, authored with Tools/generate_expansion_models.py.
Greenhouse.glb: six growing stations, LEDs, manifold, Seedling/Mature/Wilted groups. The default GLB scene shows mature plants. Two additional scenes contain seedling/wilted replacement plant groups; use only one stage at a time. The offline Unity asset retains all three groups for runtime switching.
WaterRecycler.glb: clean/used tanks, processor/filter capsules, valves and screen.
OxygenGenerator.glb: insulated cell stack, gas separators, hydrogen outlet and screen.
DustTool.glb: insulated grip, replaceable head, filaments, tether eye.
Dimensions are metres, glTF Y-up. Embedded materials, no external files. These game assets are not certified hardware drawings.
